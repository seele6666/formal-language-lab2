## 1. 项目概述

### 1.1 实验目标

本项目实现两个核心功能：

1. **CFG 化简**：对上下文无关文法依次消除 ε 产生式、单产生式、无用符号（非生成符号与不可达符号）。
2. **PDA → CFG 转换**：将**空栈接受**的下推自动机转换为等价的 CFG，并可继续调用 CFG 化简流程。

## 3. 架构设计

项目采用**三层模块化**设计：

```
┌─────────────────────────────────────────┐
│              main.py (CLI)              │
└─────────────────┬───────────────────────┘
                  │
    ┌─────────────┼─────────────┐
    ▼             ▼             ▼
 解析层        算法层        数据结构层
 cfg_parser   cfg_simplifier   cfg.py
 pda_parser   pda_to_cfg       pda.py
```

**设计原则**：

- 算法只操作 `CFG` / `PDA` 对象，与文本 I/O 解耦。
- PDA 转 CFG 的输出可直接传入 `simplify_cfg()`，实现「转换 → 化简」串联。
- 每个模块均有独立单元测试。

## 4. 核心模块详解

### 4.1 `cfg.py` — CFG 数据结构

**核心类型**：

```python
@dataclass
class CFG:
    start_symbol: Symbol
    variables: set[Symbol]
    terminals: set[Symbol]
    productions: dict[Symbol, set[ProductionRhs]]  # 右部为 tuple
```

**关键约定**：

- ε 产生式表示为**空元组** `()`，文本输出时显示为 `epsilon`。
- 单字符终结符/变量在输出时紧凑拼接（如 `abB`）；多字符符号以空格分隔（如 `[q0,B,q1]`）。

**主要方法**：

| 方法 | 功能 |
|------|------|
| `add_production(left, right)` | 添加产生式，自动维护 variables/terminals |
| `copy()` | 深拷贝文法 |
| `without_empty_left_sides()` | 确保每个变量键存在于 productions 字典 |
| `ordered_productions()` | 按 S 优先、字母序排列 |
| `to_text()` | 序列化为可读文本 |

**辅助函数**：`format_rhs()`、`EPSILON_TEXT = "epsilon"`。

---

### 4.2 `cfg_parser.py` — CFG 文本解析

**入口**：`parse_cfg(text, start_symbol=None) -> CFG`

**支持的语法**：

- 箭头：`->`、`=>`、`-->`、`:`、`=`、Unicode `→`
- ε 别名：`epsilon`、`eps`、`e`、`lambda`、`empty`、`ε`、空串
- 注释：`#` 至行尾
- 多候选右部：`|` 分隔
- 两种符号写法：紧凑（`bA`）与空格分隔（`b A`、`[q0,B,q1]`）

**分词逻辑**（`tokenize_rhs`）：

1. 若含空白 → 按空格切分。
2. 否则按已知变量名最长匹配 + 单字符 fallback。
3. 支持方括号变量名 `[q0,B,q1]`。

**起始符号**：默认取第一条产生式的左部。

---

### 4.3 `cfg_simplifier.py` — CFG 化简流水线

**主流水线**（顺序不可调换）：

```python
def simplify_cfg(grammar: CFG) -> CFG:
    no_epsilon = eliminate_epsilon_productions(grammar)
    no_units = eliminate_unit_productions(no_epsilon)
    generating_only = remove_non_generating_symbols(no_units)
    return remove_unreachable_symbols(generating_only)
```

#### 步骤 1：消除 ε 产生式

- `find_nullable_variables()`：不动点迭代，找出所有可推导出 ε 的变量。
- `_expand_nullable_rhs()`：对每个含 nullable 符号的右部，枚举删除组合（`itertools.combinations`），生成 2^k 种展开。
- 默认**不保留** `S → ε`（`keep_start_epsilon=False`）。

#### 步骤 2：消除单产生式

- 对每个变量 A，BFS 计算 `unit_closure[A]`（经 A→B 链可达的变量集）。
- 将 closure 中各变量的**非单产生式**并入 A 的产生式集。

#### 步骤 3：消除非生成符号

- `find_generating_variables()`：不动点迭代，变量 A 可生成 ⟺ 存在产生式 A→α 且 α 中所有变量均已 generating。
- 删除左部非 generating 的产生式，以及右部含非 generating 变量的产生式。

#### 步骤 4：消除不可达符号

- `find_reachable_variables()`：从 S 出发 BFS 扩展。
- 只保留左部可达、右部符号均可达的产生式。

**辅助检测函数**：`has_epsilon_productions()`、`has_unit_productions()`。

---

### 4.4 `pda.py` — PDA 数据结构

**核心类型**：

```python
@dataclass(frozen=True)
class PDAAction:
    next_state: State
    push: tuple[StackSymbol, ...]  # 空 tuple = 仅弹出

@dataclass
class PDA:
    states, input_symbols, stack_symbols
    initial_state, initial_stack_symbol
    final_states: set[State]          # 空集 = 空栈接受
    transitions: dict[TransitionKey, set[PDAAction]]
    # TransitionKey = (state, input_symbol|None, stack_top)
```

**关键属性**：`accepts_by_empty_stack` — 当 `final_states` 为空时为 `True`。

**方法**：`add_transition()` 自动维护 states/input_symbols/stack_symbols 集合。

---

### 4.5 `pda_parser.py` — PDA 文本解析

**入口**：`parse_pda(text) -> PDA`

**支持两种格式**（自动识别）：

#### 格式 A：数学符号格式

```text
M = ({q0,q1}, {a,b}, {B,z0}, delta, q0, z0, empty)
delta(q0,b,z0) = {(q0,Bz0)}
```

- 头部 7 字段：状态集、输入字母表、栈字母表、δ、初态、初栈符号、终态集。
- 迁移行：`delta(state, input, stack_top) = {(next_state, push_string)}`

#### 格式 B：块格式（推荐）

```text
states: q0 q1
input_symbols: a b
stack_symbols: B z0
start_state: q0
start_stack: z0
accept: empty_stack
transitions:
q0,b,z0 -> q0,B z0
```

**归一化**：全角标点、Unicode δ/ε/Φ 等自动转为 ASCII 等价形式。

**栈串分词**：已知栈符号集合最长匹配（如 `Bz0` → `B` + `z0`）。

---

### 4.6 `pda_to_cfg.py` — PDA→CFG 构造

**前置条件**：仅支持空栈接受 PDA（否则抛出 `NotImplementedError`）。

**变量命名**：`[p,A,q]` — 从状态 p、栈顶 A 出发，弹出 A 后到达 q 所读入的串。

**构造步骤**：

1. 变量集 = `{S}` ∪ `{[p,A,q] | p,q∈Q, A∈Γ}`，共 |Q|²×|Γ|+1 个。
2. 开始产生式：`S → [q0, z0, q]`（对所有 q）。
3. 对每个迁移 δ(p,a,A)={(q, B₁…Bₖ)}：
   - **k=0**（仅弹出）：`[p,A,q] → a`（a 可为 ε，即空前缀）。
   - **k≥1**：枚举中间状态 r₁…rₖ₋₁，`[p,A,qₖ] → a [q,B₁,r₁] [r₁,B₂,r₂] … [rₖ₋₁,Bₖ,qₖ]`。

**复杂度**：压入 k 个符号时产生 O(|Q|^k) 条产生式。

## 5. 实验指定样例

### 5.1 指定 CFG

**输入**：

```text
S -> a | bA | B | ccD
A -> abB | epsilon
B -> aA
C -> ddC
D -> ddd
```

**化简分析**：

| 符号 | 问题 | 处理 |
|------|------|------|
| A | 有 ε 产生式 | nullable；展开到含 A 的右部 |
| S→B | 单产生式 | unit-closure 将 B 的非单产生式并入 S |
| C | 非生成（C→ddC 无法终止） | 删除 |
| D | 可达且可生成 | 保留 |

**期望输出**：

```text
S -> a | aA | b | bA | ccD
A -> abB
B -> a | aA
D -> ddd
```

### 5.2 指定 PDA

**输入**（6 条迁移，2 状态，空栈接受）：

```text
M = ({q0,q1}, {a,b}, {B,z0}, delta, q0, z0, empty)
delta(q0,b,z0) = {(q0,Bz0)}
delta(q0,b,B) = {(q0,BB)}
delta(q0,a,B) = {(q1,epsilon)}
delta(q1,a,B) = {(q1,epsilon)}
delta(q1,epsilon,B) = {(q1,epsilon)}
delta(q1,epsilon,z0) = {(q1,epsilon)}
```

**识别语言**：L = { bᵐ aⁿ | m,n ≥ 1, n ≤ m }（先若干 b 压栈，再若干 a 弹栈，a 个数不超过 b）。

**化简后 CFG**（4 条产生式）：

```text
S -> b [q0,B,q1]
[q0,B,q1] -> a | b [q0,B,q1] | b [q0,B,q1] [q1,B,q1]
[q1,B,q1] -> a
```

**语义验证**（测试推导）：可生成 `ba`、`bba`、`bbaa`、`bbbaaa`；不可生成 `""`、`b`、`a`、`baa`。

## 11. 已知限制与改进方向

| 限制 | 说明 |
|------|------|
| 仅空栈接受 | 终态接受 PDA 需先转换；`pda_to_cfg` 会抛出 `NotImplementedError` |
| 不保留 S→ε | 默认完全消除 ε 产生式，即使语言含空串 |
| 压栈长度爆炸 | 压入 k 个符号时产生 O(\|Q\|^k) 条产生式 |
| 无逐步可视化 | 不支持 `--verbose` 展示化简中间步骤 |
| 命令行 only | 无 GUI/Web 界面 |
