# 形式语言与自动机实验（二）视频录制指南

> 本文档面向需要提交演示视频的小组成员，覆盖从环境准备到最终打包的完整流程。  
> 建议配合 `docs/video_script.md`（精简口播稿）与 `docs/executable.md`（命令参考）使用。

---

## 1. 要求概览

| 项目 | 要求 |
|------|------|
| 分辨率 | 720p（1280×720）及以上 |
| 时长 | 约 4 分钟（3.5–5 分钟均可） |
| 文件大小 | ≤ 100 MB |
| 内容 | 必须演示 CFG 化简、PDA→CFG、PDA→CFG+化简、单元测试 |
| 建议文件名 | `docs/demo.mp4` 或打包脚本识别的 `{组号}...视频.mp4` |
| 录制工具 | OBS Studio（推荐）或 Windows 游戏栏 |

**评分关注点**：命令输入清晰、输出与报告一致、口播说明算法要点、测试全部通过。

---

## 2. 环境搭建

### 2.1 软件清单

1. **Python 3.9+** — 终端执行 `py --version` 确认。
2. **OBS Studio** — 从 [obsproject.com](https://obsproject.com/) 下载安装。
3. **项目代码** — 克隆或解压 `formal-language-lab2` 至路径无中文空格为佳（如 `C:\projects\formal-language-lab2`）。

### 2.2 录制前自检

在项目根目录依次执行，确保全部成功：

```cmd
py main.py simplify examples\grammar_sample.txt
py main.py pda2cfg examples\pda_sample.txt --simplify
py -m unittest discover -s tests
py main.py demo
```

若使用打包 exe，额外验证：

```cmd
dist\formal_lang_lab2.exe demo
```

### 2.3 终端外观

- 字体：Consolas 或 Cascadia Mono，字号 14–16 pt。
- 背景：深色主题（与报告截图风格一致）。
- 窗口宽度：保证产生式长行不换行或换行可读。

## 3. 逐句分镜脚本

总时长约 **4 分钟**，可按表微调语速。

| 时间 | 画面 | 口播要点 |
|------|------|----------|
| 0:00–0:30 | 展示项目目录树（`cfg*.py`、`pda*.py`、`main.py`、`tests/`） | 介绍实验二两个功能：CFG 四步化简、空栈 PDA 转 CFG；说明模块化分层设计 |
| 0:30–1:15 | 打开 `examples\grammar_sample.txt`，运行 `py main.py simplify ...` | 指出 A 的 ε 产生式、S→B 单产生式、C 非生成；对照输出说明四步化简效果 |
| 1:15–2:00 | 打开 `examples\pda_sample.txt`，运行 `py main.py pda2cfg ...`（不加 simplify） | 解释 `[p,A,q]` 变量含义；说明原始 CFG 产生式较多 |
| 2:00–2:45 | 运行 `py main.py pda2cfg ... --simplify` | 展示化简后 4 条产生式；口播语言 L = { b^m a^n \| m,n≥1, n≤m } |
| 2:45–3:15 | （可选）运行 `py main.py simplify ... --verbose` | 演示 v1.2 新增逐步输出，对应报告「逐步执行追踪」章节 |
| 3:15–3:45 | 运行 `py -m unittest discover -s tests -v` | 强调 24 项测试全部 OK；提及边界用例（纯 ε、不可达、终态 PDA） |
| 3:45–4:00 | 运行 `py main.py demo` 或展示 exe | 总结：指定样例一键演示；致谢 |

## 4. 命令与预期输出

### 4.1 CFG 化简

```cmd
py main.py simplify examples\grammar_sample.txt
```

**预期输出（精确匹配）**：

```text
S -> a | aA | b | bA | ccD
A -> abB
B -> a | aA
D -> ddd
```

### 4.2 PDA→CFG + 化简

```cmd
py main.py pda2cfg examples\pda_sample.txt --simplify
```

**预期输出**：

```text
Simplified CFG:
S -> b [q0,B,q1]
[q0,B,q1] -> a | b [q0,B,q1] | b [q0,B,q1] [q1,B,q1]
[q1,B,q1] -> a
```

### 4.3 单元测试

```cmd
py -m unittest discover -s tests -v
```

**预期结尾**：

```text
Ran 24 tests in ...
OK
```

### 4.4 演示命令

```cmd
py main.py demo
```

输出含 `Specified CFG simplified:` 与 `Specified PDA converted and simplified:` 两段。

## 5. OBS 参数配置

### 5.1 场景设置

1. **来源 → 显示器采集**：选择主显示器；勾选「捕获光标」。
2. **来源 → 文本（可选）**：左上角叠加「实验二 · CFG & PDA」标题。
3. **来源 → 音频输入捕获**：若需口播，选择麦克风。

### 5.2 输出设置（设置 → 输出）

| 参数 | 推荐值 |
|------|--------|
| 输出模式 | 简单 |
| 录像质量 | 高质量，中等文件大小 |
| 录像格式 | mp4 |
| 编码器 | x264 或 NVENC（有 NVIDIA 显卡时） |
| 分辨率 | 1280×720 |
| 帧率 | 30 fps |
| 比特率 | 2500–4000 Kbps（控制 100MB 内） |

### 5.3 录制流程

1. 打开 OBS → 选择场景 → **开始录制**。
2. 切换到终端 / 资源管理器按分镜操作。
3. 结束后 **停止录制**；默认保存在 `视频` 文件夹。
4. 复制到 `docs\demo.mp4`。

## 7. 常见问题排查

| 现象 | 原因 | 处理 |
|------|------|------|
| `py` 不是内部命令 | Python 未加入 PATH | 安装 Python 并勾选「Add to PATH」，或用完整路径 |
| 输出与报告不一致 | 代码版本过旧 | `git pull` 或确认使用最新提交 |
| OBS 黑屏 | 采集权限 / 多显示器 | 以管理员运行 OBS；改采集「窗口」而非显示器 |
| 视频超过 100MB | 比特率过高 | 降低至 2500 Kbps 或缩短时长 |
| unittest 失败 | 依赖或路径错误 | 在项目根目录执行；确认 `tests/` 完整 |
| 中文路径报错 | 部分工具不兼容 | 将项目移至英文路径 |
| exe 无法运行 | 未打包或被杀软拦截 | 重新 `pyinstaller`；添加信任 |

## 8. 提交流程

### 8.1 文件放置

将成品视频保存为以下任一路径（打包脚本按优先级查找）：

```text
docs/demo.mp4
docs/{组号}2024211301张恒基视频.mp4
```

### 8.2 填写组号并打包

确认实验报告组号后，在项目根目录 PowerShell 执行：

```powershell
.\scripts\package_submission.ps1 -GroupNumber "你的组号"
```

生成：

```text
实验二{组号}2024211301张恒基.zip
```

内含：报告 docx、源码目录、exe、视频。

### 8.3 提交前 Checklist

- [ ] 视频 720p+，≤ 100MB，时长约 4 分钟
- [ ] 演示了 CFG 化简、PDA2CFG、测试、demo
- [ ] 报告 docx / pdf 与代码版本一致
- [ ] `py -m unittest discover -s tests` 全部通过
- [ ] zip 命名符合课程要求

## 附录 A：口播稿完整文本（可直接照读）

> 以下为约 4 分钟口播的完整文本，与第 3 节分镜一一对应。语速中等，约 550–650 字/分钟。

**开场（0:00–0:30）**  
大家好，这是我们形式语言与自动机实验二的演示。项目实现了两个核心功能：上下文无关文法的四步化简，以及空栈下推自动机到等价 CFG 的转换。代码采用分层设计，数据结构、解析器和算法模块相互独立，便于单元测试。

**CFG 化简（0:30–1:15）**  
这是课程指定的 CFG 样例。变量 A 有 epsilon 产生式，S 到 B 是单产生式，C 只指向自己无法生成终结符串。运行 simplify 命令后，输出中 C 被删除，epsilon 和单产生式被消除，得到等价的无冗余文法。

**PDA 转 CFG（1:15–2:00）**  
这是指定的 PDA，采用块格式输入。运行 pda2cfg 后得到原始 CFG，变量名形如方括号 p,A,q，表示从状态 p 出发弹出栈符号 A 到达 q 所读入的串。

**PDA 化简（2:00–2:45）**  
加上 simplify 选项后，原始数十条产生式化简为四条。该 PDA 识别的是先若干 b 再若干 a、且 a 的个数不超过 b 的语言。

**verbose 演示（2:45–3:15，可选）**  
v1.2 新增 verbose 选项，可以逐步查看 epsilon 消除、单产生式消除、删除非生成符号和不可达符号的中间结果，与实验报告中的逐步追踪章节一致。

**单元测试（3:15–3:45）**  
运行 unittest，共 24 项测试全部通过，覆盖解析、化简、PDA 转换、边界用例和新功能。

**结尾（3:45–4:00）**  
demo 命令可一键运行两个指定样例。演示完毕，谢谢。
